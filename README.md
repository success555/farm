## ✨ Features & Capabilities

1. **Responsive Across Any Mobile Phone & WebView**:
   - Optimized for mobile browsers (Safari, Chrome, Samsung Internet) and in-app WebViews (WhatsApp in-app browser, Facebook, Instagram, Android WebViews).
   - Sticky **Mobile Bottom Action Bar** with touch targets for instant calling, WhatsApp chats, orders, and location.
   - Smooth slide-in mobile navigation drawer.

2. **Interactive 23-Photo Authentic Field Gallery & Lightbox Carousel**:
   - Showcases 23 real on-site photos of plantain plantations, wholesale harvest stacks, high-yield suckers & corms bio-treatment, maize crop inspections, mechanized sprinkler irrigation, vertical sack nursery farming, protective respirator PPE, and youth harvest teams in Ayakoromo, Burutu LGA.
   - **Interactive Category Filter Tabs**: Filter instantly between *All Field Photos (23)*, *Plantain & Suckers (8)*, *Maize Plantation (4)*, *Irrigation & Crop Care (7)*, and *Harvest & Youth (4)*.
   - **Full Carousel Lightbox**: Includes **Next (❯)** and **Previous (❮)** navigation buttons, **Photo Counter** (e.g. *Photo 3 of 23*), keyboard arrow key support, and mobile touch swipe controls!

3. **Interactive Wholesale Produce & Order Estimator**:
   - Buyers can select produce (Plantain bunches, Cassava, Garri, Maize, Live Catfish, Smoked Catfish, Eggs, Broilers) and input quantities.
   - Automatically computes indicative bulk prices and provides **1-Click WhatsApp Order Dispatch** with a formatted order message.

4. **Community & Youth Empowerment Showcase**:
   - Highlights the three core pillars: **Grow Food**, **Grow People**, and **Grow Wealth**.

5. **Contact & Inquiry System**:
   - Instant copy-to-clipboard phone & email buttons.
   - Lead capture form connected directly to WhatsApp inquiry dispatch.
   - Comprehensive FAQ accordion addressing bulk logistics to Warri, Asaba, Benin, Port Harcourt, and Lagos.

## 🚀 How to Run Locally

### Option A: Open directly in any web browser
Simply double-click `index.html` or drag and drop it into Google Chrome, Microsoft Edge, Safari, or Firefox.

### Option B: Run via Local Python Server
In PowerShell or Terminal:
```bash
cd c:\Users\ighoe\OneDrive\Desktop\farm
python -m http.server 8080
```
Then visit: `http://localhost:8080` or `http://127.0.0.1:8080`
